## Цель

Скилл `setup-matt-pocock-skills` настроил набор под репозиторий: в `docs/agents/`
лежат три файла конфигурации (трекер, метки, доменные документы), в AGENTS.md
появился раздел `## Agent skills`.

## Действия

1. Открыть новую сессию OpenCode в корне репо (после шага 1 — скиллы уже
   загружены) и запустить скилл командой `/setup-matt-pocock-skills`.
2. Скилл сначала исследует репозиторий (remote, AGENTS.md/CLAUDE.md, docs/,
   монорепо-сигналы) и покажет, что нашёл. Сверить с ожиданиями: remote —
   GitHub (`TimG9v/ai-for-developers-project-386`), AGENTS.md существует,
   CLAUDE.md нет, `docs/agents/` нет, монорепо-сигналов нет.
3. Ответить на вопросы секциями — ответы фиксированы descripton.md:

| Секция                | Вопрос скилла             | Ответ                                                         |
| --------------------- | ------------------------- | ------------------------------------------------------------- |
| A. Трекер             | где живут задачи          | GitHub — Issues репозитория проекта (скилл сам это предложит) |
| B. Метки разбора      | оставить дефолтные метки  | да, без переопределений                                       |
| C. Доменные документы | single- или multi-context | один контекст: CONTEXT.md + docs/adr/ в корне                 |

   Нюансы поведения скилла (из его SKILL.md): секция C при отсутствии
   монорепо-сигналов пишется без вопроса; флаг «PRs as a request surface»
   остаётся `no` и не поднимается; CLAUDE.md не создаётся — правится
   существующий AGENTS.md.

4. На этапе черновика скилл покажет блок для AGENTS.md и содержимое трёх
   файлов. Проверить и подтвердить:

   - блок `## Agent skills` — структура как ниже;
   - `docs/agents/issue-tracker.md` — GitHub-шаблон: операции через `gh` CLI
     (`gh issue create/view/list/comment/edit/close`), выводы для wayfinder;
   - `docs/agents/triage-labels.md` — таблица пяти канонических меток 1:1:
     `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`,
     `wontfix`;
   - `docs/agents/domain.md` — single-context: чтение `CONTEXT.md` и
     `docs/adr/` перед исследованием, создание лениво через `/domain-modeling`.
5. Дать скиллу записать файлы, затем вычитать записанное: команды в
   issue-tracker.md используют `gh`; блок в AGENTS.md добавлен в конец,
   существующие разделы не тронуты; в triage-labels.md правая колонка совпадает
   с левой.

Ожидаемый блок в AGENTS.md (однострочные резюме сформулирует сам скилл,
структура фиксирована его шаблоном):

```markdown
## Agent skills

### Issue tracker

Issues live in GitHub Issues. See `docs/agents/issue-tracker.md`.

### Triage labels

Default five canonical roles. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context. See `docs/agents/domain.md`.
```
