## Цель

Workflow прогоняет тесты и линтеры бекенда и фронтенда на каждый push;
прогон зелёный.

## Действия

1. `.github/workflows/ci.yml`:

   - `on: push` (все ветки) + `pull_request`
   - job `backend` (ubuntu-latest, working-directory: backend):

     - actions/checkout@v4
     - actions-rust-lang/setup-rust-toolchain@v1 с toolchain 1.98.1
       (зеркалит .tool-versions)
     - Swatinem/rust-cache@v2
     - шаги: `cargo fmt --check`;
       `cargo clippy --all-targets -- -D warnings`; `cargo test`

   - job `frontend` (ubuntu-latest, working-directory: frontend):

     - actions/checkout@v4
     - actions/setup-node@v4 с node-version-file: .nvmrc
     - шаги: `npm ci`; `npm run lint`; `npm test`

2. Локальная проверка, если установлен actionlint: `actionlint`

## Файлы

- `.github/workflows/ci.yml` — новый

## Проверка

| # | Команда (real-run)             | Ожидаемый результат |
