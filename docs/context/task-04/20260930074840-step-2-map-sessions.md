## Действия (одна итерация = одна сессия)

1. Пользователь запускает `/wayfinder` с картой (номер или URL) — режим Work
   through the map. Билет можно назвать; без указания агент берёт первый фронт.
2. Агент загружает карту (низкое разрешение: тело карты, не все тела билетов),
   **claim** до любой работы:

   ```bash
   gh issue edit <n> --add-assignee @me
   ```

3. Разрешить билет по его типу (из метки):
   - `grilling` — скиллы `grilling` + `domain-modeling`: вопросы пачкой,
     рекомендации агента, решения пользователя; термины немедленно в CONTEXT.md;
   - `research` — субагент со скиллом `research`, находки — в комментарий;
   - `prototype` — скилл `prototype`: дешёвый артефакт, ссылка из билета;
   - `task` — работа руками, ответ фиксирует сделанное.
4. Записать решение:

   ```bash
   gh issue comment <n> --body "<ответ>"
   gh issue close <n>
   ```

   и дописать строку-указатель в `## Decisions so far` карты (gist + ссылка).
5. Выпустить из тумана то, что ответ сделал определимым: новые билеты
   (create-then-wire, блокировки вторым проходом), graduated патчи стереть из
   `Not yet specified`. Решение, оказавшееся за destination, — out of scope.
6. Конец сессии. Повторять итерации, пока фронт не опустеет.

Правила скилла: ≤1 билета за сессию (research не в счёт); агент не отвечает за
пользователя в HITL-билетах; по ходу — термины в `CONTEXT.md` (формат `## Language`),
ADR по трём условиям сразу (трудно обратить + удивительно + trade-off), следующий
номер `0002`.
