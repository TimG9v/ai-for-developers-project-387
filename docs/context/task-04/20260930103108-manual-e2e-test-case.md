# manual-e2e-test-case

- Дата: 2026-09-30 10:31
- Ветка: task-4 (рабочая)
- Шаг: кейс ручного e2e-тестирования — сценарии владельца и гостя

Назначение: ручная приёмка фичи «запись на звонок» на реальном запуске.
Часть A применима уже сейчас; часть B активируется, когда вертикальные тикеты
(после `/to-tickets`, шаг 8 плана) реализуют эндпоинты и страницы. Каждый пункт
части B трассируется к решению карты.

## Общие предусловия

- Репозиторий в ветке `task-4`, зависимости установлены (npm, cargo).
- Запуск: `make dev` — backend на `127.0.0.1:8081`, frontend — порт из вывода
  `next dev` (по умолчанию 3000).
- API-проверки без UI — curl по контракту `openapi/openapi.yaml` на :8081
  (формы запросов — из спеки, поля в camelCase).

## Критерий прохождения

Часть A — все пункты зелёные перед каждым PR шагов 4–6. Часть B — весь столбец
«Ожидаемый результат» совпал на приёмке фичи (после тикетов); расхождение
фиксируется тикетом, а не правкой кейса задним числом.
