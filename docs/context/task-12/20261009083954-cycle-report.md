## Наблюдения (для будущих задач)

- `timezone:` под `schedule` — валидный синтаксис (docs, fetch
  2026-10-09); cron расписания считается в Europe/Moscow. Ошибка
  «это невалидный ключ, значит UTC» стоила одного докоммита —
  проверять устаревшие знания о синтаксисе по живым docs.
- Тесты, зависящие от «завтра», — мина замедленного действия:
  будни зелёные, пт/сб UTC красные (CI кажется «флаки», хотя падение
  детерминировано). Предикат даты в тесте = доменный предикат
  (`expected_window_days` ↔ `domain.rs` окно записи).
- `issues: read` у ревью выдержал три живых прогона (PR #40/41/42:
  37870403343, 37871224935, 37871733116) — понижение безопасно.
- Подстрока `/oc` не входит в `/opencode` — сужение if до `/oc`
  действительно убирает самопробуждение на ссылках opencode.ai
  (живой skipped теста A; семантика contains осталась у mentions
  самого экшена — унаследовано из task-8).
- `gh pr merge --merge` требует «ветка актуальна base» — при отставшей
  ветке PR не мержится даже с зелёными проверками; рецепт: rebase на
  origin/main + push --force-with-lease (безопасно для непушеной/своей
  ветки).
- Замечания агентного авторевью к собственному PR — полезный сигнал:
  одно было ошибочным (timezone), второе точным (Security cron) —
  каждое проверялось по первоисточнику, а не принималось на веру.
