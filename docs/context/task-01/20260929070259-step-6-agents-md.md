правило про формат коммитов. Выполняется последним — после каркаса,

инициализировать нечего).

## Действия

1. Запустить инициализацию агента (/init в OpenCode — выполняет
   пользователь) либо агент составляет AGENTS.md по логике /init,
   изучив собранный каркас
2. Содержимое (минимум):

   - обзор в одну строку: календарь; бекенд Rust/axum, фронтенд Next.js
   - команды: dev (cargo run / npm run dev), test (cargo test /
     npm test), lint (clippy + fmt / npm run lint); make-цели в корне
   - структура: backend/, frontend/, .github/workflows/
   - правило: коммиты по Conventional Commits (feat:, fix:, chore:,
     ci:, docs:) — формат касается и коммитов агента
     (требование step-1.md)

3. Сократить до рабочего минимума: только команды, устройство и
   правила, которые из кода не читаются (ориентир — до ~50 строк)
