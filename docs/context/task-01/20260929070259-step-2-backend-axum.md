## Цель

Работающий бекенд на axum: health-endpoint, интеграционный smoke-тест
(приложение поднимается и отвечает), линтеры. Ориентир — официальный
getting started axum (axum.rs / репозиторий tokio-rs/axum), а не память
модели о версиях.

## Действия

1. В корне репозитория: `cargo new backend`
2. `backend/Cargo.toml` — зависимости по getting started:

   - `axum` — последняя стабильная (версию не фиксируем: берём
     актуальную из документации на момент реализации)
   - `tokio` — features = ["full"]

3. `backend/src/main.rs`:

   - функция `app() -> Router` — вынесена для переиспользования в тесте
   - роут `GET /health` → JSON `{"status":"ok"}`
   - `main`: bind на 127.0.0.1:8080 и serve (порт 8080: 3000 оставляем
     будущему фронтенду)

4. `backend/tests/smoke.rs` — smoke-тест «поднимается и отвечает»:

   - сервер из `app()` стартует в задаче на 127.0.0.1:0 (случайный порт)
   - фактический порт читается из listener
   - запрос `GET /health` отправляется сырым HTTP через `TcpStream`
     (без новых зависимостей)
   - assert: ответ содержит `HTTP/1.1 200`

5. Линтеры: `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings`
