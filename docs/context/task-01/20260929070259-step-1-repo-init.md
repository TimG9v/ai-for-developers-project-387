## Цель

Подготовить корень репозитория: правила игнора, зафиксированные версии
инструментов, корневой Makefile, основная ветка `main`.

## Действия

1. Переименовать ветку `master` → `main` (делает пользователь,
   у агента git read-only): `git branch -m master main`
2. Дополнить `.gitignore` (сейчас только `context/tmp*`):

   - `target/` — сборка Rust
   - `node_modules/`
   - `.next/`
   - `dist/`
   - `*.tsbuildinfo`
   - `.env*.local`

3. Создать `.tool-versions`: `rust 1.98.1` (asdf)
4. Создать `.nvmrc`: `25.2.0` — фиксация Node для CI
   (actions/setup-node читает .nvmrc) и будущих сессий
5. Создать `Makefile` с целями dev / test / lint:

   - backend — cargo (заработает после шага 2)
   - frontend — npm (заработает после шага 3)
   - до шагов 2–3 цели по несуществующим директориям падают —
     это нормально, CI на них пока не ссылается
