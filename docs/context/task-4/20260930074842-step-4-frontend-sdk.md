## Цель

Из `openapi/openapi.yaml` генерируется типизированный клиентский SDK; фронтенд
может им пользоваться — требование `descripton.md` («проверьте, что фронтенд может
им пользоваться»). Минимальная проверка: сборка и тест, импортирующие
сгенерированный клиент. Страницы бронирования — не этот шаг, они придут тикетами
после шага 8.

## Предусловия

1. Шаг 3 выполнен: `openapi/openapi.yaml` существует и коммитится.
2. Инструмент генерации выбран картой (research-билет шага 2); рекомендация —
   `@hey-api/openapi-ts`: он назван в Ссылках `descripton.md` и генерирует
   типы + функции вызова из OpenAPI 3.

## Действия

1. Установка и конфиг в существующем frontend-пакете:

   ```bash
   cd frontend && npm install --save-dev @hey-api/openapi-ts
   ```

   `frontend/openapi-ts.config.ts`:

   ```ts
   import { defineConfig } from "@hey-api/openapi-ts";

   export default defineConfig({
     input: "../openapi/openapi.yaml",
     output: { path: "src/client", format: "prettier" },
   });
   ```

2. Скрипт генерации в `frontend/package.json`:

   ```json
   "scripts": {
     "generate:client": "openapi-ts"
   }
   ```

3. Сгенерировать:

   ```bash
   cd frontend && npm run generate:client
   ```

4. Проверка «фронтенд может им пользоваться»: тест, импортирующий типы и функцию
   SDK по имени операции контракта. `frontend/tests/sdk.test.ts`:

   ```ts
   import { describe, expect, it } from "vitest";
   import { createBooking, getEventTypes, type Booking } from "../src/client";

   describe("generated SDK", () => {
     it("exposes typed calls for contract operations", () => {
       expect(typeof getEventTypes).toBe("function");
       expect(typeof createBooking).toBe("function");
       const sample: Booking = {
         id: "b1",
         slotId: "s1",
         guestName: "Гость",
         guestEmail: "g@example.com",
         createdAt: new Date().toISOString(),
       };
       expect(sample.slotId).toBe("s1");
     });
   });
   ```

   Поля `Booking` сверить со сгенерированным типом: имена полей приходят из
   контракта шага 3 (решения карты), при расхождении правится контракт, не тест.

5. Прогнать тесты и сборку фронтенда (real-run):

   ```bash
   cd frontend && npm test && npm run build
   ```

## Файлы

- Create: `frontend/openapi-ts.config.ts`, `frontend/src/client/**` (генерат)
- Modify: `frontend/package.json` (devDependency + script)
- Create: `frontend/tests/sdk.test.ts`
- Generate-код коммитится (требование: «сгенерированное руками не правится»
  предполагает, что он в репо и неизменяем вручную).
