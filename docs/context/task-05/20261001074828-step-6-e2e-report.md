## Корневое расхождение: тикет #20

`fetch` с origin `:3000` на `:8081` блокируется браузером: preflight
`OPTIONS` → 405 без `Access-Control-Allow-Origin`; из страницы —
`TypeError: Failed to fetch`. Все клиентские операции (B1, B2, B3-календарь,
B4, B7-UI) неработоспособны в браузере. Шовные тесты (мок SDK) и SSR это не
ловят по построению. Решения на выбор — в тикете (#20): Next rewrites
(тот же origin) либо CORS-слой на backend.

## Примечания

- Серверная валидация дважды поймала ошибки тестовых данных прогона (интервал
  40 мин при типе 30 мин → 400) — правило «длительность слота определяется
  типом» работает и мимо UI.
- Попутный факт: `pkill -f "cargo run"` в shell убивает саму команду
  (self-match) — перезапуск backend делался `pgrep -x backend` + `kill`.
