# Owner-API без проверки доступа

Авторизации в проекте нет, поэтому API владельца (создание типов встреч и
слотов, список записей) доступен без проверки: роль владельца поддерживается
только отдельным маршрутом админки в UI, а владелец — один заранее заданный
профиль. Охранять эндпоинты в этом шаге нечем и незачем; когда появится
авторизация, проверка добавится на этих же эндпоинтах.
